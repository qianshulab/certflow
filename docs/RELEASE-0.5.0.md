## 已知问题与升级说明

v0.5.0 在进程异常退出后可能遗留 `.run.lock`，使容器重启后的自动运行被锁阻止。遇到此状态，应先确认此前的 lego、DNS 桥接及部署子进程均已结束，再检查运行记录；不要在有运行中进程时直接删除锁文件。另一个边界是：管理证书已成功签发并通过校验，但同一任务的后续部署失败时，HTTPS 入口可能继续使用旧 TLS 上下文，直到后续成功运行或重启。升级到 v0.5.1 前应关注管理证书剩余有效期及任务失败记录。v0.5.1 针对两项问题增加修复，验收结果另见 [v0.5.1 记录](RELEASE-0.5.1.md)。

上述现场结果只覆盖本次部署时可观察的行为。后续每次管理证书续期、目标服务导入或网络环境改变，都应重新核对实际握手和应用所呈现的证书。
