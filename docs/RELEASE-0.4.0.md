# CertFlow 0.4.0 发布计划与验收记录

本轮目标：面向个人在绿联 DXP4800 Docker 中持续管理证书，完成深色工作台、任务管理与运行检查，并通过 GitHub Actions 构建经过验证的 Linux 镜像。

## 发布顺序与放行条件

1. 逐项审查当前功能，修复能复现的正确性和安全问题，补回归测试。
2. 完成界面改造并检查正常、空、加载、失败和未保存状态。
3. 独立复核核心、服务端、权限边界和部署文件。
4. 推送源码到公开仓库，运行 Windows / Linux 测试及真实容器验证。
5. 只有所有必需检查成功后发布版本镜像；验证公开镜像可拉取，记录版本与不可变摘要。

## 本轮已发现并处理的问题

- 旧状态仅查看证书到期日期。现同时校验私钥、完整域名集合和生效时间，无效证书不显示可用。
- 一个任务的状态文件损坏可阻断其他任务。现按任务隔离，保留损坏数据，不静默覆盖。
- 批量任务不能单独暂停。新增 `enabled`，批量及自动检查跳过暂停任务，仍可明确单次执行。
- 增加环境检查与整套 PEM ZIP 下载；ZIP 使用系统实现验证兼容性。
- 审查发现备份归档可能被误加入 Git，已补充专用备份目录与归档忽略规则。
- 运行检查增加遗留运行锁、部署锁与损坏状态检查，检查本身不修改这些文件。
- 超时操作终止子孙进程；无法确认终止时保留运行锁及部署恢复信息，中止批次，避免残留命令与重试 / 回滚并发。
- 云端 Windows 测试发现目录扫描与临时日志文件替换的竞态。明文泄漏检查改在服务完全停止后执行，保持完整扫描范围；同时修复关闭服务时应先等待在途保存请求，再等待最后日志落盘的窗口。新增回归已证明旧实现失败、新实现通过。

独立复核已覆盖核心状态与部署、凭据、导出边界、运行检查、Docker 测试真实性及待提交文件。检测到的私钥仅为明确标注 TEST-ONLY 的测试样本。修复后的 Windows 本地回归结果为 103 项：101 通过，2 项环境条件跳过；最终云端验收结果如下。

额外端到端验证使用独立临时目录及虚构凭据，实际经过 HTTP 登录、加密保存 DNSPod 凭据、服务端启动任务、核心状态处理、证书及私钥校验、ZIP 下载、暂停任务保存、批量跳过暂停任务、CLI 状态查询，以及重启后的凭据加载。只有外部 ACME 执行器替换为固定测试证书；未修改用户配置，也未进行真实 DNS / CA 操作。此链路通过。

浏览器验收使用实际运行的 0.4.0 服务：四个模块导航、待申请筛选、搜索空结果、只读环境检查、凭据显隐、无效任务 ID 校验、跨页面与轮询后的草稿保留、确认撤销、未签发时禁止导出均通过。窄屏四个模块检查通过，证书表格在容器内横向滚动，页面没有横向溢出；修复了初次检查发现的表格撑宽问题。浏览器检查未发现 JavaScript 错误或警告。未保存真实凭据、未修改用户配置、未代替用户接受 CA 条款。

交互复核另外修正了无 DNS 凭据时有效证书的部署重试入口、警告日志样式和历史部署状态文案。界面中的部署结果表示历史操作记录，不等于已验证当前公网服务使用的证书。

实际截图保存在 `docs/gui-preview.jpg` 与 `docs/gui-credentials.jpg`，主工作台截图已由另一位审查者检查。登录页导航被浏览器扩展拦截，本轮只做登录页面源码检查和认证 API 测试，不将其视觉验收计作通过；实际证书下载、暂停保存、部署重试由核心及 API 测试覆盖，浏览器未使用真实证书执行这些操作。

## 外部验证与边界

尚未获得真实域名、DNS 凭据和 NAS 运行环境。自动化验证不能代替真实 DNS 权限、证书机构签发、NAS 实机导入、宝塔或远端 Nginx 重载验证。

UGOS 管理页面仍需在续期后手动导入并关联新证书。自动部署仅限容器 / 运行主机可访问的目录和命令；默认 Compose 不挂载 Docker socket。

异常退出遗留锁不会按 PID 猜测删除。应确认相关进程全部停止后处理。私钥缺失 / 不匹配时优先从备份恢复同一批证书与私钥；不要反复重试来规避 CA 限额。
